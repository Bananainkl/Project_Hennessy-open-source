# Hennessy 1.7.11

Initial public source release of the native media downloader, library, and player.

## Highlights

- Native SwiftUI macOS application and experimental Android companion.
- Download planning, local library management, playback, artwork, lyrics, and metadata workflows.
- GPL-3.0 source with explicit third-party dependency notices.

This source release does not include media, `yt-dlp`, or FFmpeg binaries. Verify all applicable licenses before distributing a self-contained package.
